## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git (for development)
- A text editor or IDE

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/tanyanxi/tanyanxi.github.io.git
   cd tanyanxi.github.io
   ```

2. **Open locally**
   ```bash
   # Open index.html in your browser
   open index.html
   # or
   python -m http.server 8000  # For a local server
   ```

3. **View the site**
   Navigate to `http://localhost:8000` in your browser
